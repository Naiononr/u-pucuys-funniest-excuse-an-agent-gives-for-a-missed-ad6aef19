`main.py` (Python 3, stdlib only, deterministic, no network) writes one short excuse — 111 characters, a single line — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`), via an `os.open` with mode `0o644` plus a `chmod 0644`, and verifies the written bytes afterwards.
